Plume is a fire, smoke and explosion simulator (Python 3.13 and NVIDIA Warp) that renders flipbook sheets
for Petri (`chadmv/petri`, Godot 4.7), built for an agent to drive: write a TOML recipe, run it, read the
contact sheets and numbers, change a value, run again. Governing docs are `CLAUDE.md`, the design brief
(`docs/specs/2026-11-07-plume-design-brief.md`, decisions D1 to D34), the spec
(`docs/specs/2026-11-07-plume-design.md`) and the build plan (`docs/plans/2026-11-07-plume-slices.md`).
The project is building its first version in six slices in the D34 order; slice 1 (the smoke puff end
to end) is done, and slice 2 (solver quality and iteration tools) is next. Each slice ends with the
user's look review of its example recipe, a golden `numbers.txt` and a retro. The question every slice
answers is whether the effect Petri needs passes the user's look review against the art reference.
Hard requirements: the sheet contract exactly as the brief states it; byte-identical outputs (all but
`timing.txt`) between identical runs on the same machine and device; a CPU path for cloud sessions and
CI; previews under 10 s on the 2080 Ti and 30 s on CPU; a default run under 60 s on the 2080 Ti by the
end of slice 6.
